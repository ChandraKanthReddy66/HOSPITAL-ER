# 🏥 HOSPITAL ER – Emergency Room Analytics Dashboard

## 📌 Project Overview

The Hospital ER Dashboard is an end-to-end data analytics project developed to analyze Emergency Room operations and patient activity.

The project follows the workflow:

**Excel/CSV → SQL Server → Power BI**

The source data was loaded into SQL Server and connected to Power BI for data transformation, analysis, KPI development, and dashboard visualization.

## 🎯 Business Objective

The objective of this project is to provide insights into Emergency Room performance and patient activity.

The dashboard analyzes:

- Patient admission patterns
- Patient volume
- Average wait time
- Patient satisfaction
- Department referrals
- Patient demographics
- Peak days and hours
- Patients seen within 30 minutes
- Operational trends
